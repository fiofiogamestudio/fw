# 素材中心

美术工作台的首个页面是“素材中心”。默认显示当前素材的一个大视口和“想怎么改”输入，出现结果后才显示原版与修改后的对比。产品、目录、包和 CLI 统一使用 FWV / `fwv`；现有工程清单与素材目录保持不变。

## 一次修改

1. 选择素材，直接填写“想怎么改”。图片可以先拖动圈选位置。名称自动从要求生成；需要指定保持条件、历史版本、像素坐标或部件/动作时，再展开相应详情。
2. 点击当前的主按钮。“准备给 AI”会记录确切源版本并准备可复制内容，接着复制给当前 AI、完成后导入结果；它不会自行唤醒外部 AI。“生成预览”会记录要求并调用已配置的图像服务，完成后点击“查看生成结果”。尚未配置服务时，主按钮进入真实设置页面，不创建生成任务。执行设置按需展开，并记住当前项目的选择。
3. 出现结果后，在相同尺度、缩放和背景下对比原版与修改后。预览上方始终保留“用这版”“继续修改”“这版不用”。“用这版”顺序调用人工接受和采用，为原素材新增版本；“这版不用”记录驳回。所有历史文件与候选保留。

“继续修改”在尚未采用时回到该请求的原素材，采用后从刚采用的确切版本开始。界面会说明当前来源，不把未采用结果自动变成新基线。已有要求和结果可从“版本与修改记录”“结果详情与评审记录”查看，后者也保留分开的接受、采用及文件检查操作。

技术检查通过只说明文件和格式可用，美术效果仍由用户判断。一键采用固定点击时的请求、候选和评审/采用状态；另一个窗口已经改变决定时会提示冲突。接受成功但采用失败时保留已接受状态，重试只执行采用；响应丢失时先重读记录，已确认采用成功就按成功显示，不重复生成。

## 选区保护

图片请求包含选区时，回填与图像服务结果默认只替换选区内像素。后台先把完整候选映射回基线画布尺寸，再合成选区；选区外保留基线像素。原始生成/导入候选仍保留，界面显示实际的输入尺寸、回装尺寸和保护状态。

选区是“完整画面中的局部区域”，外部工具应输出保留完整构图的图片。部件名称和动作时间用于定位问题；实际骨骼或权重修改需要进入对应专业控件，生成可检查的文件候选。

## 保存与版本

| 操作 | 保存什么 | 是否更新当前素材 |
| --- | --- | --- |
| 顶部保存 / Ctrl+S | FWE `changeDrafts` 中的问题参数、选区及 Spine 修复参数 | 否 |
| 撤销 / 重做 | 当前参数草稿、画布选区和 Spine 修复参数 | 否 |
| 准备请求 / 生成预览 / 记录修改要求 | 固定问题、要求、源版本与定位，再执行对应操作 | 否 |
| 导入 / 接收候选 | 候选文件、确切版本、来源及技术检查 | 否 |
| 接受 / 驳回 | 候选的人工评审决定与意见 | 否 |
| 采用候选 | 原素材的新版本及采用记录 | 是 |
| 用这版 | 顺序记录接受并采用当前确切候选 | 是 |

旧工程没有 `changeDrafts` 或修改请求记录时，读取时补充空集合，不删除原有换皮、拆件、图片、生图或 Spine 草稿。取消浏览器或切换工具不会自动撤销模型调用、删除候选或清除评审。

## 专业工具与范围

图片加工、立绘拆件与绑定、骨骼与动作预览、角色换皮继续作为独立工具入口，并带入适用的当前素材与版本。素材中心针对实际素材类型显示专业工具。

### Spine 骨骼与权重修复

选择 Spine 4.2 JSON 素材后，默认仅显示真实素材、动作和时间。骨骼与网格叠加默认关闭；展开“骨骼与权重工具”才显示结构、父级、约束、涉及动作、网格与顶点权重。选择骨骼及动作时间，再点击“把骨骼、动作与时间记为问题定位”，将当前定位带入请求。

工具中可修改当前骨骼的初始位置、旋转、缩放、剪切、长度以及允许的父级。界面仅提供满足现有骨骼顺序的父级。独立加权网格可选择顶点和已有影响骨骼，修改一个权重；其余已有影响按比例分配并归一化。关联网格、被共享的权重和未加权附件只读，原因直接显示。

“生成修复预览”只提交当前骨骼实际改变的字段和所选顶点权重；如果尚未建立请求，会先使用已填写的要求记录源版本。切换骨骼会载入另一个骨骼的基线参数。候选在独立版本中保存真实 JSON；动画时间线、贴图与 Atlas 保留。它复用普通候选的“用这版”及评审记录。自然语言本身用于描述要求，当前不会自动转换成骨骼数值修改。

基线与候选均由官方 Spine Runtime 读取实际文件，以源版本的相机范围、相同皮肤、动作和时间对比，默认查看 setup pose。可以叠加骨骼和网格线；候选旁显示字段与权重修改前后的明细。修改初始骨骼可能影响约束与动作结果，需要同时检查相关动作。当前不编辑动画时间线、不增加影响骨骼，也不自动重建绑定。

### 3D 模型、贴图与绑定

素材中心可导入 GLB 并进入“3D 模型与绑定”，支持实际材质、贴图、蒙皮、骨骼及动作检查，骨骼局部 TRS 与既有四个影响的权重修复，以及贴图提取、AI 图片修改和确切版本回装。专业视口使用同一相机与动作时间对比真实候选。首版限单个内嵌 buffer、内嵌 PNG/JPEG 的 GLB 2.0，其他格式未适配。专业页未建立的输入暂存于当前页面；建立请求才固定基线、意图与锚点。完整范围见 [3D 模型工作流](model-workbench.md)。

普通布局、字段、状态、按钮和文案由 `assets.ui.json`、`spine-repair.ui.json` 等 FWE 配置描述；草稿约束来自 `authoring.fwe`。原有专业页面收在 FWE 原生“工具”工作区，旧路由和草稿继续可用。单/双视口使用 FWE 动态列数，“保存草稿 / 撤销草稿 / 重做草稿”使用应用标签；本轮没有新增私有 CSS 或普通控件工厂。应用代码负责命令适配、草稿生命周期和专业位图/WebGL 视口。持久化和 API 合同见 [修改请求与候选](art-changes.md)。

## 验证

`npm run test:assets-browser` 创建隔离工程、原创图片与独立 Chrome profile，检查一个主输入、自动标题、单/双视口、真实指针圈选、草稿保存/撤销/重做、文件回填、一键采用的部分失败和响应丢失恢复、并发驳回保护、采用后的确切基线、旧工具导航及宽/窄窗口布局。图像服务使用本机 mock，验证 `/images/edits` 带上确切源图、选区外保护和未配置时不误派发，不调用商业模型。报告和截图保存在 `.local/reports/assets-browser/`。

`npm run test:spine-repair-browser` 使用本地原创加权网格，检查真实骨骼/权重读取、问题锚点、参数保存及撤销/重做、字段与顶点的精确修改、其余文件保留、官方 Runtime 同相机同时间渲染、评审采用，以及关联网格只读和切换无候选素材后的视口。报告与截图在 `.local/reports/spine-repair-browser/`。
