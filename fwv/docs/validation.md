# 2D 编辑器验证

当前验收范围只包含 2D 图片浏览，以及区域附着和加权网格骨骼动画编辑。删除功能的历史验收记录不作为当前能力说明。

当前一轮实际结果见 [2026-10-03 验证记录](verification-2026-10-03.md)。

```powershell
npm.cmd test
npm.cmd run test:gallery2d-browser
npm.cmd run test:skeleton2d-browser
```

单元和真实文件/HTTP 集成覆盖文档采样、文件篡改、版本保存、并发冲突、写锁、原子替换、索引大小、CLI、FWE 草稿、HTTP 会话和禁用旧入口。旧草稿和历史资产的兼容性必须在不启用旧功能的条件下成立。

FWE 公共接口回归覆盖 DSL 筛选配置的编译保留、Surface 原生有效性与表单必填收紧，以及按字节限额读取请求体。FWD 集成实际保存并回读超过 8 MiB 的中文草稿，验证超过 16 MiB 领域限额时磁盘保持不变。

图库浏览器验收覆盖普通图片、自定义多图资产、骨骼贴图、PNG/JPEG/WebP、FWE 原生列表／网格及分页、历史版本筛选、搜索、画布像素、骨骼导航以及纯浏览不标记草稿修改。状态图验收检查原图单卡归组、按派生文件名搜索、详情默认折叠与状态切换、确切文件/像素，以及延迟旧请求后的快速切换不会串图。目录单测另覆盖孤儿状态、独立来源/参考/预览图、未知后缀和版本隔离，确保归组后全部登记图片仍可访问。FWE 通用缩略图、分页和 Form 生命周期另由该组件的 `test:browser:catalog` 验收，防止专业模块重新接管集合浏览。

骨骼浏览器验收覆盖画布像素、动作播放、骨骼与部件编辑、关键帧、撤销/重做、草稿重载、新修订回读、导出和不同角色的编辑隔离。

`test/skeleton2d-canvas.test.mjs` 是真实 Canvas 像素回归，覆盖半透明完整仿射网格与区域绘制一致、T 接点不产生内部裂线、凹形和非中线孔洞保留、混合刚性/变形区域的共享边、外沿不漏、折叠面重叠及覆盖缓存随原地编辑失效。`npm ci` 安装固定版本的 `@napi-rs/canvas` 开发依赖；也可在运行 `npm test` 前设置 `FWV_CANVAS_MODULE` 为已有 Canvas 模块的文件 URL。缺少实现会使测试失败，像素回归不允许静默跳过。

绘制回归验证的是渲染几何和像素行为。它不证明宿主切图有足够遮挡层、动作全帧无美术裂口、肢体形变自然或符合参考图；这些需要宿主用真实角色另行验证。大网格还应记录实际姿态、分辨率和运行环境的绘制耗时，原生 Canvas 离屏计时不能当成浏览器帧率。

额外检查直接注册 FWE Form、卸载后普通字段监听器归零、原生 DAG 骨骼选择、顶栏保存、无效速度/空关键帧不提交，以及合法小数精度保留。目录配置检查读取真实编译结果，防止原生默认筛选在 DSL 到运行时之间丢失。

两项浏览器验收需要 Node.js 22+ 和 Chrome/Chromium，默认读取同级 `../fwe`，可用 `FWV_BROWSER_FWE_PATH` 显式覆盖。测试使用独立 headless 浏览器配置及独立美术工程，报告与截图写入 `.local/reports/gallery2d-browser/`、`.local/reports/skeleton2d-browser/`。实际宿主全角色检验可使用 `tools/verify-skeleton2d-library-browser.mjs`，宿主适配测试另行执行。技术校验与浏览器可用性通过，不代表美术效果已获人工验收。
