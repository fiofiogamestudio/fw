`starport-font.ttf` is a subset of Noto Sans SC from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/notosanssc

Original: `NotoSansSC[wght].ttf`, retrieved 2026-09-14. License: `OFL.txt`.
The subset contains the current demo/runtime UI characters plus printable ASCII.
It was generated using FontTools (`subsetter.populate(text=...)`), with no glyph
shape modification. Add new characters by regenerating this subset from the
upstream font. This small demo font is not a general-purpose Chinese font.
